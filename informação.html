01 — O que são Frameworks Web?

São estruturas que oferecem ferramentas, componentes e recursos prontos para facilitar o desenvolvimento de aplicações web.

02 — HTML e CSS

O HTML organiza os elementos da página, enquanto o CSS define cores, fontes, tamanhos e posicionamentos.

03 — Bootstrap

É um framework front-end que disponibiliza classes e componentes prontos para criar interfaces organizadas e responsivas.

04 — Classes na prática

Classes como .container, .bg-primary, .text-white, .rounded e .p-4 ajudam a construir e personalizar páginas.

O que significam essas classes?

  • container: centraliza e organiza o conteúdo.
  • bg-primary: aplica uma cor de fundo azul.
  • bg-danger: aplica uma cor de fundo vermelha.
  • text-white: deixa o texto branco.
  • rounded: arredonda os cantos.
  • p-4: adiciona espaçamento interno.
  • navbar: define uma barra de navegação.
